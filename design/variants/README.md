# 선택 패널 시안 (2026-11-12)

현재 3D 화면에서 **서버·시청자를 선택했을 때 나오는 상세 패널**을 그래프 중심으로 바꾼 시안 모음입니다.

- **먼저 볼 것:** `index.html`을 엽니다. 썸네일 갤러리이고, 배치·구성·테마로 거를 수 있습니다.
- **각 시안:** `NNN-<배치>-<구성>-<테마>.html`. 바탕은 `../central-overview-3d.html`(현재 시안)이고, 선택 패널만 다릅니다.
  - 3D 장면에서 서버(랙), 시청자(모니터), origin을 눌러 보면 됩니다. "+10"을 누르면 시청자가 늘어납니다.
  - 인터넷이 필요합니다(three.js CDN, Google Fonts).
- **캡처:** `shots/NNN-edge.jpg`(edge-01 선택), `shots/NNN-viewer.jpg`(viewer-b84c 선택), 1600×900.
- 모든 숫자는 예시입니다. 실제 대시보드에 없는 값(메모리, 브라우저, 네트워크 종류, QoE 점수 등)도 시안에는 들어 있습니다.

## 조합

| 축 | 종류 |
|---|---|
| 배치 10 | 오른쪽 서랍, 아래 시트, 떠 있는 카드, 왼쪽 넓은 패널, 집중 창, 사이드바 교체, 벤토 타일, 탭 서랍, HUD 카드, 화면 분할 |
| 구성 10 | KPI+영역, 게이지+스파크라인, 히트맵+분포, 진단 문장+타임라인, 전체 대비 비교, 레이더+점수, 미니멀 큰 숫자, 화질(레이어) 중심, 분포 띠, 운영자 터미널 |
| 테마 10 | 네이비 글래스(현재), 그래파이트, 프로스트 라이트, 네온 사이버, 선셋, 터미널 그린, 오로라, 고대비, 노르드, 오션 틸 |

배치 × 구성 = 100개이고, 테마는 각 배치·구성에 10종이 한 번씩 돌아가도록 섞었습니다.

**추가 101~120: 종합안.** 위 구성들에서 좋은 요소(1초 최대·throttle 숫자 타일, CPU 평균/최대, 화질 분포, 요약 문장, 주의 시청자 / 시청자 QoE 점수+원인, 화질 타임라인, 같은 서버 대비 loss 띠, 이벤트)를 합친 구성을 배치 10종(현재 테마)과 다른 테마들에 입혔습니다.

**추천 10개**는 `picks.json`에 이유와 함께 있고, 갤러리 맨 위에 나옵니다. 가장 추천은 110(화면 분할 · 종합안).

## 다시 만들기

```bash
node _shared/gen.mjs        # 120개 HTML (바탕 시안이 바뀌면 다시 실행)
python -m http.server 18777 --bind 127.0.0.1   # 이 폴더에서
node _shared/capture.mjs all   # 캡처 (Chrome 필요)
node _shared/index.mjs      # 갤러리
```

- `_shared/kit.js`: 예시 데이터, SVG 차트(영역·선·띠·막대·쌓은 영역·히트맵·히스토그램·도넛·게이지·링·bullet·타임라인·레이더·box), 구성 10종
- `_shared/kit.css`: 패널 공통 스타일과 배치 10종
